Questions fréquentes

Pourquoi Windows affiche un avertissement ?

Le fichier n’est pas encore signé numériquement, ce qui est courant pour les petits projets. Clique sur « Informations complémentaires », puis « Exécuter quand même ».

Est-ce gratuit et sûr ?

Oui, gratuit et sans pub. Le code est public : tu peux le lire sur GitHub (lien en bas de page).

Ai-je besoin de Java ?

Oui, Java 21 ou plus pour les versions récentes de Minecraft. Tu peux l’installer gratuitement depuis adoptium.net.

Comment marchent les mises à jour ?

À l’ouverture, le launcher regarde s’il existe une nouvelle version. Si oui, il te la propose, la télécharge et se relance.

Puis-je jouer sur des serveurs officiels ?

Oui avec la connexion Microsoft, si tu possèdes Minecraft Java. Sans compte, le mode hors-ligne marche en solo et sur les serveurs en mode offline.
